# CineMap 🎬

Flutter приложение для поиска и коллекционирования фильмов.

## Возможности

- 🔍 **Поиск** — живой поиск фильмов, сериалов и аниме через TMDB API
- 📚 **Коллекция** — сохранение любимых фильмов локально
- 🏆 **Челленджи** — задания для настоящих киноманов
- 🗺️ **Карта** — интерактивная карта мест съёмок (в разработке)

## Запуск

```bash
flutter pub get
flutter run
```

## Технологии

- Flutter 3.x
- Riverpod (state management)
- TMDB API
- cached_network_image
- shared_preferences
- google_fonts
